# 📖 Sobre

Este projeto apresenta a trajetória completa de Obito Uchiha, desde sua infância em Konoha até sua redenção durante a Quarta Grande Guerra Ninja.

O objetivo é reunir informações sobre sua história, poderes, batalhas, técnicas e evolução em um site moderno, responsivo e com visual inspirado no universo de Naruto.

# 🚀 Como executar

Clone o projeto

```bash
git clone https://github.com/SEU-USUARIO/obito-website.git
```

Entre na pasta

```bash
cd obito-website
```

Abra

```
index.html
```

ou utilize o Live Server do VS Code.
